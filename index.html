Como publicar isso de graça no GitHub Pages?

  1. Crie um repositório público no GitHub (ex: gerador-arquivos).
  2. Salve este código em um arquivo chamado index.html.
  3. Faça o upload ou envie (git push) para a branch principal (main) do seu repositório.
  4. Vá nas configurações do repositório (Settings) > Pages e ative o Deploy a partir da branch main. Pronto!
