Como publicar no GitHub Pages?

Esta aplicação funciona inteiramente no lado do cliente (Client-Side). Para hospedá-la gratuitamente no GitHub Pages:

  1. 1
    Crie o Repositório:

    Crie um repositório público no GitHub (ex: gerador-ficheiros).

  2. 2
    Salve como index.html:

    Salve todo o código deste ficheiro com o nome exato index.html.

  3. 3
    Upload no GitHub:

    Envie o index.html para a branch principal (main).

  4. 4
    Ative o Pages:

    Em Settings > Pages, escolha a branch main e salve!
