Como hospedar este app de graça no GitHub Pages?

  1. Crie um repositório público no GitHub (ex: gerador-arquivo).
  2. Salve todo este código em um arquivo chamado index.html.
  3. Faça o upload do arquivo para a branch principal (main) do seu repositório.
  4. Vá em Settings > Pages e selecione a branch main para o deploy. Pronto!
